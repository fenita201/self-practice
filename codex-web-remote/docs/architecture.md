# Kiến trúc và hợp đồng

Fastify API + static React cùng origin. Codex app-server child lâu dài qua NDJSON stdio; stdout chỉ protocol, stderr không log payload nhạy cảm. Adapter correlation ID, timeout 30s, server requests lưu pending ID; failure đánh dấu unknown, không retry turn/start. Metadata usage dùng Promise.allSettled, cache chung/poll interval; không model calls. Type bindings sinh từ binary 0.161.0, experimentalApi được khai báo vì requestUserInput/account usage.

SQLite schema1 (transaction migration, PRAGMA user_version, từ chối schema mới hơn app) / WAL chứa scrypt hash, cookie token hash/TTL/CSRF, thread ownership/policy, submissions với unique clientRequestId và event journal. Startup chỉ backend đổi active/dispatching thành unknown; doctor/password không làm đổi trạng thái turn. Request submission được lưu trước dispatch. Retry cùng ID/payload trả bản cũ; khác payload trả conflict. Không bảo đảm exactly-once upstream xuyên crash trước khi nhận turn ID, vì vậy không tự resubmit. Browser reconnect hoàn toàn read-only.

Metadata được lấy qua thread/list/read. Thread mới/loaded có snapshot metadata từ runtime để không phụ thuộc read RPC trong lúc đang có active turn. History dùng thread/turns/list full items, thread/items/list riêng, không raw JSONL. View all có all sourceKinds, backend tiếp tục page upstream khi filter loại bớt; response page có thể lớn hơn 20 khi lấy trọn page cuối để không làm rơi session. Có nextCursor, không công bố total giả. Search chỉ tên/preview. Sources do binary báo có thể là vscode dù clientInfo là web; ownership lấy DB không giả sourceKinds.

Session do instance tạo có ownership web. Session CLI/instance khác không điều khiển; kể cả trong roots vẫn read-only session. Ngoài roots/mất cwd không IDE. Source/status/ownership là ba thông tin riêng; notLoaded không chứng minh external idle. CLI probe thật không nhận notification live, chỉ có history persist; không resume/start-turn để attach. Sau restart web kiểm tra runtime khi chủ đích gửi turn tiếp theo; nếu resume báo active thì chặn dispatch. Ownership không phải distributed lock với mọi external client.

Journal persist trước broadcast, monotonic seq. SSE Last-Event-ID/cursor, snapshot canonical item theo turnId/itemId + stream reconcile. Item completed là authoritative, command outputDelta và message/summary deltas cập nhật item. Reasoning raw text/content bỏ trước journal/API; chỉ public summary. Retention không xóa active/waiting events, checkpoint pruned báo gap; hard budget tính byte payload JSON (DB/WAL/index overhead riêng), phát storage error và khóa send. Không silently claim complete output. Download dùng NDJSON generator. Render 400 items một lượt, tải thêm trước và log download. SSE slow client >4MiB buffer đóng để reconnect; heartbeat kiểm tra TTL/session revoke.

Files realpath confinement; read symlink chỉ trong project; write từ chối symlink ở mọi ancestor. UTF-8 fatal decoder/binary/size checks; etag SHA256 nội dung; mode + CRLF/LF; write temp cùng thư mục + fsync + kiểm tra version lần nữa + rename. Create wx / mkdir exclusive. Rename không đè đích/root, khóa mutation tránh các API web chạy đồng thời. Lock bao gồm project ancestors/children và turn/start; active/waiting turn chặn save/create/rename. External writer không tham gia lock, vẫn có race ngoài phạm vi bảo đảm.

Watcher polling 1s (WSL mounted drive không phát inotify qua đường này), ignore generated dirs, depth6/max8, lifecycle response-close. Clean tab reload; dirty tab giữ draft, báo changed/missing; draft gắn project gốc. Mobile read-only editor mặc định, desktop sửa ngay. Ctrl+S dùng handler chung. Markdown React renderer không raw HTML, không executable output.

Auth scrypt salted hash; random cookie stored SHA256, HttpOnly/SameSite Strict/Secure HTTPS. Mutation Origin đúng PUBLIC_URL + CSRF; GET/stream Origin nếu có phải đúng, SameSite ngăn cross-site cookie. Login bounded attempts/IP; no arbitrary RPC/shell browser API. Auth metadata browser chỉ type/plan không email/token. Probes health/ready không tiết lộ project/auth. Service không root; PROJECT_ROOTS không sandbox shell.
